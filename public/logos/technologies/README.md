# Logos del loop superior

Sustituye cada archivo SVG por el logotipo definitivo conservando exactamente su nombre y su ubicación. Se recomienda usar SVG con fondo transparente y formato cuadrado (`viewBox="0 0 64 64"`).

Los archivos `flutter.svg`, `react-nextjs.svg`, `nodejs.svg`, `excel.png` y `apps-script.svg` son placeholders para tecnologías con marca propia y están preparados para que los reemplaces por sus logos oficiales.

Los demás SVG son iconos personalizados para las aptitudes del loop superior. Comparten el degradado azul–cian, el fondo redondeado y el trazo blanco del diseño de la web. Los archivos de marcas tecnológicas se conservan en esta carpeta como reserva, pero no aparecen en el loop.
